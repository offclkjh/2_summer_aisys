## 문제에서 주어진 정보

중심 사례 하나만 사용한다. 모든 수치, 기호 의미, shape, dtype을 여기에 공개한다.
문제를 정의하는 정보와 정답을 공개하는 정보를 구분한다. 학습자가 예측하거나
구현해야 하는 구체적인 결과, 완성 식, 완성 코드 예시는 먼저 제시하지 않는다.

## 구현 도구 구분

- 직접 구현: 이 세션에서 배우는 개념. 이 계산을 완성 함수 하나로
  대체하지 않는다.
- 사용 권장 API: indexing, reduction, 선형대수 primitive 등 개념을
  표현하는 도구. 직접 재구현하지 않는다.
- 검산 전용 API: 필수 구현을 완성하고 예측을 기록한 뒤에만 사용한다.

세 범주에 해당하는 구체적인 식·함수를 세션별로 명시한다. 단순히
"라이브러리 사용 금지"라고 쓰지 않고, 무엇을 직접 구현해야 하는지 밝힌다.
