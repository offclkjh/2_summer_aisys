# `math.linear_system` — 선형계

- 필요한 수준: `Ax=b`의 객체와 shape를 식별한다.
- 뜻: 행렬 `A`와 벡터 `b`가 주어졌을 때 이를 만족하는 `x`를 찾는 문제다.
- 진단: `A`가 `(3,3)`, `b`가 `(3,)`일 때 `x`의 shape를 말하고 아래 2x2 선형계를 푼다.

```text
x + y = 3
x - y = 1
```

- 최소 복습: 두 식을 더하면 `2x=4`이므로 `x=2`, 다시 대입하면 `y=1`이다. 수치 코드에서는 역행렬을 만들기보다 `solve(A, b)`를 사용한다.
- 예제: `A=I`이면 해는 `x=b`다. 위 선형계는 `A=[[1,1],[1,-1]]`, `b=[3,1]`로 쓴다.
