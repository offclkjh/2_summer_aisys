# `math.vector_matrix` — 벡터와 행렬 곱

- 필요한 수준: 곱이 가능한 shape와 결과 shape를 판단한다.
- 뜻: `(m,n) @ (n,p)`의 안쪽 차원 `n`이 같아야 하며 결과는 `(m,p)`다.
- 진단: `(5,3) @ (3,2)`의 결과 shape를 말하고 `[1,2] @ [3,4]`를 계산한다.
- 최소 복습: 각 결과 원소는 왼쪽 행과 오른쪽 열의 내적이다. 내적은 같은 위치 원소를 곱해 더한다.
- 예제: `(5,3) @ (3,2)`의 결과는 `(5,2)`이고 `[1,2] @ [3,4] = 1*3 + 2*4 = 11`이다.
