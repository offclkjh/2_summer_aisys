# `math.derivative` — 미분과 gradient

- 필요한 수준: scalar 미분과 여러 파라미터의 편미분 벡터를 구분한다.
- 뜻: 미분은 입력의 작은 변화에 대한 출력 변화율이고 gradient는 편미분을 모은 벡터다.
- 진단: `f(w)=w^2`의 도함수와 `w=3`에서의 값을 구한 뒤 `f(w1,w2)=w1^2+2w2^2`의 gradient를 쓴다.
- 최소 복습: `d(w^2)/dw=2w`이다. 여러 입력이면 각 입력에 대한 편미분을 같은 순서로 모은다.
- 예제: `f(w1,w2)`의 gradient는 `[2w1, 4w2]`다. gradient의 반대 방향은 국소적으로 함수를 줄이는 방향이다.
